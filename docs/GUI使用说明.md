# HTML 可视化编辑器 · GUI 使用说明

> 本应用为开发者提供 HTML 的可视化点选编辑与本机 Agent 直改两种工作方式，强调对原文件的最小改动与可回退。界面整体为「桌面工具深色外壳 + 文档白色画布」，点击页面元素会在右栏出现对应操作区。

---

## 1. 界面总览

```
┌──┬─────────────────────────────────────────────────────────┬──────────────────┐
│  │ 可视化 | 源码 | 预览   /path/to/file.html   打开 保存 另存为 │ Agent: codex     │  ← 顶栏
│左│─────────────────────────────────────────────────────────│ 目标卡片          │
│轨│ 可视化编辑：单击文字/图片可选中字段并在右栏修改…            │ 整块重排范围       │  ← 右栏
│  │                                                         │ 人工修改区         │
│编│              HTML 页面画布（iframe）                      │ 让 Agent 修改区    │
│辑│                                                         │                  │
│  │                                                         │ 修改记录（无选中时）│
│设├─────────────────────────────────────────────────────────┴──────────────────┤
│置│ 可视化 | 已保存 N 字符 | M 条修改 | Agent: codex                            │  ← 状态栏
└──┴─────────────────────────────────────────────────────────┴──────────────────┘
```

- **左轨**：编辑器 / 设置。
- **顶栏**：模式切换、文件路径、打开 / 保存 / 另存为·导出 / 关闭文件·完成 / 退出。
- **右栏**：上下文操作区（随是否选中元素变化）。
- **状态栏**：模式 / 保存状态 / 字符数 / 修改条数 / 当前 Agent。

---

## 2. 打开文件

- 顶栏点「打开」，选择本地 `.html` / `.htm` 文件。
- 载入后同时保留两份状态：原始源码（用于精准回填）和页面预览（左中画布）。
- 浏览器环境下为文件选择器；桌面环境下直接读取本地文件。

---

## 3. 三种模式

| 模式 | 用途 |
|---|---|
| **可视化** | 页面以 iframe 呈现，悬停高亮元素，点击选中并在右栏修改；这是默认编辑模式 |
| **源码** | 直接编辑原始 HTML 文本，适合查看回填结果或做整体调整 |
| **预览** | 页面自身功能（按钮、链接等）可正常操作，不触发编辑选中 |

切换模式不影响已记录的人工修改。

---

## 4. 人工编辑

### 4.1 选中与点选反馈

在「可视化」模式下：

- 鼠标悬停页面元素，画布中显示高亮轮廓；
- 单击后，右栏顶部出现目标卡片，显示命中元素的 DOM 路径与原文片段；
- 红框等轮廓只是编辑辅助，不会写入保存后的 HTML。

### 4.2 修改文字

在右栏「人工修改」区：

- 整段替换文字：在应用文字框填写新内容，应用到选中元素。
- 保存时只对源码里对应的文本节点做替换，元素的标签、属性、样式、缩进保持不变。
- 若页面由 JS 动态渲染导致源码定位不到，会用页面加载后的固化脚本兜底。

### 4.3 替换图片

- 对图片元素，点「替换图片」选择本地图片，转为 base64 内联写入，避免外部链接失效。
- 大图会按设置做等比缩放，避免文件过大。

### 4.4 插入内容

- 以选中元素为锚点，可选择插入到它的**之前 / 之后 / 开头 / 末尾**。
- 可插入文字或图片；插入内容会作为新的源码片段写入锚点附近。
- 保存时会过滤重复写入，确保选择一次图片只插入一张。

### 4.5 删除

- 对选中元素点「删除」，该区块会从页面和最终文件中移除。

### 4.6 回退与重做

- 右栏「人工修改」区顶部显示「已修改 N 处」，并提供：
  - **↩ 回退上一步**
  - **↪ 重做**
- 对不满意的人工修改，可回退到修改前内容；回退 / 重做即时反映在画布预览与最终保存结果中。
- 无选中元素时，右栏显示完整修改记录列表，可逐条撤销。

## 5. 让 Agent 修改

### 5.1 前提

- 顶栏 `Agent:` 已选择当前 Agent（codex / cbc）。若显示「未找到 Agent」，请到「设置 → Agent」发现并注册本机 Agent。
- 所选 Agent 需已在其 CLI 中登录（codex 用 `codex login`，cbc 用 `cbc /login`）。桌面客户端的登录态与 CLI 不互通。

### 5.2 操作步骤

1. 在可视化模式下**先点击选中要修改的元素**（这一步很关键，选中信息会作为唯一修改目标传给 Agent）。
2. 右栏「让 Agent 修改」区填写一句话指令，例如：「把当前表格改成分层信息图」。
3. 可附加截图辅助说明。
4. 点「交给 Agent 修改」。按钮显示「Agent 修改中…」，此时界面仍可操作，不会卡死。
5. Agent 直接修改真实文件。完成后程序自动重新读取文件、刷新预览，并跳回「可视化」模式。
6. 若结果不满意，点「还原到修改前」，用调用前自动生成的备份覆盖恢复。

### 5.3 关于选中上下文

你选中的元素名称、DOM 路径、原文片段会作为「唯一修改目标」传给 Agent，避免它把「当前表格」理解成别的章节。因此**修改前务必先点选目标元素**，不要只写指令不选中。

### 5.4 安全机制

- 调用前自动生成 `<文件名>.hve-backup-<时间戳>.html` 备份。
- Agent 在干净临时目录中启动，避免被工作区里的 `AGENTS.md` / `.ccg` 工作流干扰而重写整页。
- 异步执行 + 超时保护；文件字节未实际变化时判为失败，不误报成功。

---

## 6. 保存与导出

- **保存**：将当前结果写回原文件；保存成功后清空修改记录、重置基线，避免再次重放导致重复插入。
- **另存为 / 导出**：生成新文件，原文件保持不变。
- 浏览器环境下「保存」降级为下载文件。

---

## 7. 设置

左轨点「设置」，只有一个 **Agent** 页：

- 显示发现到的本机 Agent 列表（codex / cbc / codebuddy 等）；
- 可设为当前 Agent；
- 可手动添加本机 Agent 路径。

旧版「模型」「外部调用」页签已移除。

---

## 8. 常见问题

**Q：点击元素没反应？**
确认处于「可视化」模式。预览模式下点击只会触发页面自身交互，不会进入编辑。

**Q：保存后格式变了？**
本工具按源码区间精准回填，未改动处字节级保留。若使用了源码模式做整体编辑，格式由你的输入决定。

**Q：Agent 修改后文件没变化 / 改错位置？**
先确认已点选目标元素（选中上下文是唯一目标），再确认 Agent CLI 已登录。若改错，用「还原到修改前」恢复后重试。

**Q：Agent 修改时界面卡住？**
正常情况下异步执行不会卡界面。若长时间无响应，600 秒超时会自动终止并提示；可检查 Agent 客户端状态后重试。

**Q：提示 Agent 未登录 / 认证失败？**
桌面客户端登录态与 CLI 不互通，请在终端对所选 Agent 执行登录命令。

---

## 9. 原型文件

`GUI界面原型.html` 是可交互的静态界面原型（开发阶段用于界面评审），不代表真实数据，也不能用于编辑文件。真实功能请使用桌面应用或 `npm run dev` 启动的前端。
