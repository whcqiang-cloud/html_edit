# HTML 可视化编辑器技术方案

版本 v5.0，2026 年 11 月 19 日。

配套文件：`GUI使用说明.md`（操作手册）、`../README_CN.md`（项目说明）。（历史 GUI 界面原型为本地文件，已排除出版本控制，不在仓库中提供。）这份文档描述当前实现与设计取舍，不放大段代码。

> v5.0 相对 v4.0 是**架构换代**：放弃「Agent 生成改动计划 + 四层校验 + 设置三页签」的中间层，改为 **Agent 直接改真实文件**（agentic 直改）。旧文档里的 `call_agent` / `probe_model` / 模型绑定 / 外部调用 / 改动预览 / 四层校验等描述均已失效。

## 1. 产品定位与范围

一个纯本地的桌面工具（Tauri 2 + React + TypeScript），解决两个场景：

- **人工精确编辑**：可视化点选页面元素，改文字 / 换图 / 插入 / 删除，保存时对原 HTML 做源码级精准回填，未改字节保持不变。
- **Agent 直改**：把本地 HTML 文件连同用户选中的元素，交给本机 Agent（codex / cbc）直接读取、修改、保存；调用前备份，失败或不满意可一键还原。

### 两条路线，一个目标

| 路线 | 入口 | 写盘方式 |
|---|---|---|
| 人工编辑 | GUI 点选 + 右栏面板 | 前端 `finalize()` → 源码级 patch → `saveHtmlFile` |
| Agent 编辑 | 右栏「让 Agent 修改」 | 本机 Agent 直接改磁盘文件 → 前端重新读取 |

两条路线都追求「最小改动、可回退」，但实现完全不同：人工走前端精准 patch，Agent 走后端子进程直改。

### 明确不做

- 不生成改动计划预览、不做四层校验（已随 agentic 架构移除）
- 设置页只有 Agent 一项，不做「模型」「外部调用」页签
- 不通过 HTTP 调用模型（相关前后端代码已清理）
- 不托管密钥、不做运行记录 / 任务队列 / 用量页面

## 2. 界面结构（`src/App.tsx`）

### 2.1 布局

- **左轨**：两个入口 —— 编辑器 / 设置（`view: "editor" | "settings"`）。
- **顶栏**：模式切换（可视化 / 源码 / 预览）、文件路径、文件按钮（打开 / 保存 / 另存为·导出 / 关闭文件·完成 / 退出）、右上 `Agent：<name>`。
- **右栏上下文面板**：
  - 有选中元素时：目标卡片 → 整块重排范围选择 → 人工修改区（含回退 / 重做）→ 让 Agent 修改区。
  - 无选中时：修改记录列表 + 撤销 / 重做。
- **状态栏**：模式 / 保存状态 / 字符数 / 修改条数 / 当前 Agent。

### 2.2 设置页

只有 Agent 一项（`SetTab = "agent"`）：发现的本机 Agent 列表、设为当前、添加本机 Agent 表单。配置文件里的 `models` / `proto` 字段仅为兼容旧配置保留，不参与运行。

### 2.3 关键状态

`sourceHtml` / `originalHtml` / `docHtml`、`modifications` / `history` / `redoStack`、`selectedField`、`frameKey`（iframe 强制重载）、`agentInstruction` / `agentBusy` / `agentResult` / `agentShot`。

## 3. 人工编辑链路

### 3.1 点选

`iframeBridge.ts` 在 iframe 的 Document 上安装捕获阶段监听：悬停高亮、点击回传选中元素、预览模式放行页面自身交互、重载后按 document 重新绑定。点选结果存为 `FieldSelection`（fieldPath / blockPath / 名称 / 原文片段 / 类型）。

### 3.2 编辑操作

| 操作 | 函数 | 机制 |
|---|---|---|
| 改文字 | `applyTextEdit` | 整段替换（`innerText` / `innerFrom`） |
| 换图 | `applyImageEdit` | `selectLocalImage` 转 base64，替换图片节点 |
| 插入 | `applyInsert` | 以 `selectedField.fieldPath` 为锚点，位置 before / after / prepend / append |
| 删除 | `applyDelete` | 记录 `type: "delete"` 的 modification |
| 回退 / 重做 | `undo` / `redo` | 切换 modification 的 `reverted` 标志，`finalizeWith` 跳过已回退项 |

### 3.3 源码级回填（`htmlPatch.ts`）

- `getNodePath` 生成 `tag:nth-of-type(n)` 路径；`findNodeRange` 用标签栈扫描源码并逐层校验父链，避免兄弟分支误命中。
- `applyEditsTracked` / `applyEdits` 按原始偏移排序、用 delta 补偿偏移做字符串替换；同时追踪哪些 edit 真正写入源码。
- 源码定位不到的动态渲染节点，用 `injectFreezeScript` 生成的固化脚本在页面加载后重放；`injectLightbox` 注入图片灯箱。
- **防重复插入**：`finalizeWith` 只把「未成功写入源码」的 edit 交给固化脚本，已写入源码的插入不再固化，避免同一处插入两次。保存成功后清空 `modifications` / `history` / `redoStack` 并重置基线。

## 4. Agent 直改链路（`src-tauri/src/main.rs`）

### 4.1 命令

后端注册 5 个命令：`read_config` / `write_config` / `discover_agents` / `agent_edit_file` / `restore_agent_backup`。无 HTTP 模型调用命令。

### 4.2 `agent_edit_file` 执行流程

1. 校验 `file_path` 为绝对路径且是文件。
2. **备份**：`<名>.hve-backup-<毫秒时间戳>.html`，失败即返回。
3. 记录改动前字节 `before`。
4. **临时工作目录**：创建 `hve-agent-work-<pid>-<stamp>` 作为子进程 cwd，`TempWorkDir` 的 `Drop` 自动清理。目的：切断 Agent 按目标文件所在目录自动加载 `AGENTS.md` / `.ccg/tasks` 的链路，防止局部修改被放大成整页重写。目标文件始终用绝对路径传入。
5. **选中上下文**：前端把选中元素的名称、字段、DOM 路径、原文片段（≤400 字）、类型拼成 `selection`，后端注入 prompt 最前「【最重要 — 唯一修改目标】」块，明确「指令里的『我选择内容 / 当前表格』只指它，其他章节相似内容一律不动」。
6. **强约束 prompt**：声明局部定点编辑，禁止 `cat >` / 重定向 / 整文件覆盖，要求用字符串替换或 apply_patch，且与 AGENTS.md / .ccg / 外部模型审查无关。
7. **命令构造**：codex 用 `codex exec -s workspace-write --dangerously-bypass-approvals-and-sandbox --skip-git-repo-check [-i 截图] <prompt>`；workbuddy/codebuddy/cbc 用 `cbc -p <prompt> -y`。
8. **子进程环境**：增强 PATH（`resolve_program` 解析裸名绝对路径、`augmented_path` 补 homebrew 等目录解决 GUI 找不到 node 的问题）、`CODEX_AGENT_TYPE=hve-editor` 与 `CODEX_FORK_TURNS=none`（让 CCG hook 走 sub-agent 分支，忽略工作流）、piped 输出、`kill_on_drop(true)`。
9. **异步 + 超时**：`tokio::process::Command` 异步等待，600 秒超时自动终止，界面不卡死。
10. **成功判定**：退出码 → 认证失败关键词检测 → **前后字节比对**（文件未变化一律判失败，防止 cbc 未登录却以 0 退出误报成功）。

### 4.3 还原

`restore_agent_backup` 用备份 `fs::copy` 覆盖目标文件；前端还原后重新读取并刷新。

## 5. 配置与兼容

- `read_config` / `write_config` 读写应用配置目录下的 `config.json`，不写进 HTML、不含明文凭证。
- `config/index.ts` 的 `agents` / `currentAgentId` 为活跃字段；`models` / `proto` / `ModelDef` / `ProtoSettings` 仅为兼容旧配置文件保留，UI 与运行逻辑不再使用。
- `src/lib/` 中 `agentEdit.ts` / `adapters/` / `blockRenderer.ts` 是旧计划链路遗留，当前 App 不引用，仅被测试脚本使用；`providers/` 无引用。它们在测试覆盖与向后兼容上有价值，暂保留。

## 6. 安全与边界

- Agent 直接改真实文件，以**调用前备份 + 一键还原**作为安全网，替代旧的计划预览与四层校验。
- 失败判定以「文件字节是否真的变化」为准，避免未登录 / 无权限时误报成功。
- 目标文件用绝对路径，命令在干净临时目录执行，避免工作区级指令干扰。
- 认证凭证由 Agent 自身登录态提供（codex 用 `codex login`，cbc 用 `cbc /login`），工具不保存、不回显。
- 浏览器降级环境不支持 Agent 编辑（返回明确提示）。
