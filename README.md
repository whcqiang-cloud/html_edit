# HTML 可视化编辑器（本地桌面工具）

面向**开发者内部**的轻量桌面工具：像使用 Word 一样**可视化编辑 HTML**，点击页面元素即可修改文字 / 替换图片 / 删除区块，保存时**源码级精准回填**，未改动处原格式 100% 保留。

基于 **Tauri 2 + React + TypeScript** 构建，安装包体积小、启动快、纯本地、不依赖云端。

---

## 功能

- 👆 **点击即编辑**：鼠标悬停高亮元素，点击弹出操作条，直接修改文字或替换图片
- ➕ **插入文字/图片**：以选中元素为锚点，在前面 / 后面 / 开头 / 末尾插入新段落或图片
- 🗑 **删除区块**：一键删除选中的整个元素区块
- 📝 **修改记录**：右侧面板列出所有改动，可逐条撤销或一键清空
- 🎯 **源码级精准保存**：仅替换修改的节点区间，未改动的原始 HTML 字节 100% 保留（不依赖 DOM 序列化）
- 💾 **文件操作**：打开本地 .html、保存（覆盖）、另存为 / 导出 .html
- 🌐 **跨环境兼容**：Tauri 桌面端和纯浏览器环境均可运行（浏览器端自动降级为文件选择 / 下载）

## 环境要求

- Node.js ≥ 18
- Rust 工具链（cargo / rustc）—— 用于 Tauri 桌面端编译
- macOS / Windows / Linux 均可（Tauri 跨平台）

## 安装与运行

### 1. 安装依赖

```bash
npm install
```

### 2. 开发模式（带热更新）

```bash
npm run tauri dev
```

> 不带 Tauri 时也可仅跑前端预览：`npm run dev`（文件打开/导出会自动降级为浏览器文件选择/下载，便于调试 UI）。

### 3. 打包为桌面应用

```bash
npm run tauri build
```

产物位置（macOS 示例）：

```
src-tauri/target/release/bundle/
├── dmg/      HTML可视化编辑器_1.0.0_x64.dmg
└── macos/    HTML可视化编辑器.app
```

> 未签名时 macOS 可能被 Gatekeeper 拦截，可右键「打开」或在终端执行：
> `codesign --force --deep --sign - "src-tauri/target/release/bundle/macos/HTML可视化编辑器.app"`

## 使用流程

1. 打开应用 → 点击「打开」载入本地 .html 文件。
2. **左栏**为可视化预览，鼠标悬停元素会出现蓝色虚线框。
3. 点击元素 → 弹出浮动工具条，选择操作：
   - **编辑文字**：修改元素文本内容（保留原有标签结构）
   - **替换图片**：输入新的图片 URL
   - **插入 ▾**：在下拉中选择「插入文字」或「插入图片」
     - 插入文字：选择类型（段落/标题/列表项/分割线）并输入内容
     - 插入图片：输入图片 URL 和可选 alt 文本
     - 选择插入位置：前面 / 后面 / 开头 / 末尾（以锚点元素为参照）
   - **删除区块**：删除整个元素
4. **右栏**显示所有修改记录（含插入记录，带 ➕ 标识），可逐条撤销或一键清空。
5. 点击「保存」覆盖原文件，或「另存为」导出为新文件。
6. 状态栏显示原始字符数和修改条数。

## 核心原理

### 源码级精准回填

传统富文本编辑器通过 DOM 序列化生成 HTML，会丢失原始格式、缩进、注释等。本项目采用**源码字符串精准替换**方案：

1. **节点定位**：用 `tag:nth-of-type(n)` 路径描述元素在文档中的位置（不依赖 id/class）。
2. **标签栈扫描**：保存时从源码字符串起始位置扫描，按路径计数匹配目标节点，精确得到其在源码中的 `start/end` 字节偏移。
3. **字符串替换**：直接在源码字符串上替换对应区间，其余字节原样保留。

这样保证了**未修改的部分一个字节都不会变**，最大程度保留原始 HTML 的格式和注释。

## 扩展建议（开发者向）

- **增加属性编辑**：在浮动工具条中增加编辑 class / style / href 等属性的功能。
- **插入新元素**：支持在指定位置插入新的 HTML 元素或组件模板。
- **撤销/重做栈**：当前仅支持撤销已记录的修改，可扩展为完整的 undo/redo 历史。
- **多文件项目管理**：用 Tauri `fs` 读写目录，增加侧边文件树。
- **图片本地化**：替换图片时把远程图转为 base64 内联，保证导出文件自包含。
- **CSS 样式面板**：选中元素后，右侧显示可编辑的 CSS 属性面板。
